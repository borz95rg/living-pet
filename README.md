# Живой питомец — Android MVP

Офлайн-MVP игры в Android Studio. Экран и игровая логика лежат в `app/src/main/assets/index.html`; Kotlin-оболочка запускает их во встроенном WebView. Сохранение питомца лежит в приватных Android SharedPreferences. В приложении есть плавающий значок питомца: нажми лапку в шапке, выдай разрешение показываться поверх окон и перетаскивай значок. Нажатие на него открывает игру; выключить режим можно из уведомления «Питомец рядом».

## Открыть в GitHub Desktop

1. Распакуйте ZIP в отдельную папку.
2. В GitHub Desktop выберите **File → Add local repository…** и укажите распакованную папку.
3. Если GitHub Desktop скажет, что это не Git-репозиторий, нажмите **create a repository** для этой папки.
4. Для сборки приложения откройте папку `living-pet-android` в Android Studio и дождитесь синхронизации Gradle.

## Сборка APK

В Android Studio выберите **Build → Build APK(s)**. APK появится в `app/build/outputs/apk/debug/`.

## Автоматическая сборка на GitHub

Workflow `.github/workflows/android.yml` собирает debug и release APK при каждом push в `main` или `master`. Скачай файлы на странице репозитория: **Actions → последний запуск Build Android APK → Artifacts**. При push тега вида `v0.1.1` workflow также создаёт GitHub Release.

Без signing secrets release APK соберётся неподписанным и не установится как обновление; debug APK годится для первой проверки, но его подпись на GitHub runner временная. Чтобы собирать устанавливаемые обновления, один раз создай собственный ключ и добавь в **Settings → Secrets and variables → Actions → New repository secret**:

- `ANDROID_KEYSTORE_BASE64` — Base64-содержимое файла `.jks`.
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища.
- `ANDROID_KEY_ALIAS` — alias ключа.
- `ANDROID_KEY_PASSWORD` — пароль ключа.

В PowerShell ключ можно создать командой `keytool -genkeypair -v -keystore living-pet-release.jks -alias livingpet -keyalg RSA -keysize 2048 -validity 10000`. Base64 для секрета: `[Convert]::ToBase64String([IO.File]::ReadAllBytes('living-pet-release.jks'))`. Храни `.jks` и пароли вне GitHub-репозитория и сделай резервную копию: без этого же ключа Android не установит новую версию поверх старой.

## Обновления и сохранения

У приложения закреплён ID `ru.livingpet.app`, а сохранение имеет версию схемы. Сборка обновления с тем же ID и тем же ключом подписи устанавливается поверх предыдущей и сохраняет данные приложения. Для публикации нужно сохранить свой release signing key в надёжном месте и подписывать им каждое следующее обновление. Не удаляйте приложение перед обновлением: удаление стирает локальные данные. Google Play может включить резервное копирование приложения, но перенос сохранения на новое устройство требует отдельной проверки.

Нужны Android Studio с Android SDK 35 и доступ к сети для первой загрузки Gradle-плагинов. Сам экран питомца после установки работает без сети.

## Что реализовано

- Выбор собаки, кошки, лисицы или волка с отдельными темпераментами и репликами.
- Пять этапов взросления; прогресс учитывает время и добрые взаимодействия.
- Комната с погодой и временем суток, смена поведения и наряда.
- Тап по питомцу, игра, разговорные карточки, исследование и журнал воспоминаний.
- Автосохранение на устройстве; отсутствие игрока не уменьшает прогресс и не вредит питомцу.

Это MVP: плавающий значок пока статичный, реальная погода, микрофон, виджет, сюжет и реакции на уведомления ещё не подключены. Формат сохранения нужно расширять миграциями, сохраняя чтение предыдущей версии при добавлении новых функций.
