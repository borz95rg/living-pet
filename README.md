# Живой питомец — Android

Офлайн-игра для Android. Приложение загружает экран и игровую логику из `app/src/main/assets/` во встроенный WebView. Сохранение хранится в приватных Android SharedPreferences, отдельно от кэша WebView; обновления мигрируют старую схему, сохраняя питомца.

## Возможности

- Четыре питомца, пять стадий роста, показатели самочувствия и автономное поведение.
- Плавающая 3D-лисица с резервной 2D-анимацией.
- Пять загадочных находок, повторяемые экспедиции с выбором и журнал последствий.
- Дом питомца: можно менять лежанку, игрушку и украшение; новые вещи открываются по мере роста и прохождения истории.
- Локальное сохранение; игровой прогресс не отправляется в сеть.

## Android Studio

Откройте корень распакованного проекта — папку с `settings.gradle.kts`, `app/` и `.github/`. Нужны JDK 17 и Android SDK 35. В Android Studio выберите **Build → Build APK(s)**; отладочный APK появится в `app/build/outputs/apk/debug/`.

## GitHub Desktop и ZIP

ZIP содержит исходники без `.git`. Чтобы обновить уже подключённый репозиторий, распакуйте архив и скопируйте его содержимое поверх локальной копии репозитория, сохранив папку `.git`. Затем в GitHub Desktop проверьте изменения, создайте commit и нажмите **Push origin**.

Workflow `.github/workflows/android.yml` запускается при отправке изменений в `main` или `master` и собирает debug и release APK. Файлы сборки можно скачать на странице репозитория: **Actions → последний запуск → Artifacts**.

Для устанавливаемых release-обновлений нужен тот же ключ подписи во всех сборках. В **Settings → Secrets and variables → Actions** добавьте `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` и `ANDROID_KEY_PASSWORD`. Не удаляйте приложение при обновлении: удаление стирает локальное сохранение. Резервную копию `.jks` храните отдельно от репозитория.

## Сборка и подпись

Java и Kotlin компилируются с JVM target 17. Workflow увеличивает `versionCode` для каждой сборки; Android устанавливает обновление поверх приложения только при совпадении ID `ru.livingpet.app` и ключа подписи.
