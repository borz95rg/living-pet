# 3D-движок лисы (three.js)

* `fox3d.js` — рендер: загрузка GLB, шейдер меха из 14 слоёв, материалы глаз и носа, свет
  день/ночь, мягкая тень, смешивание анимаций, моргание, взгляд за пальцем, прогулка по комнате.
* `pet3d.js` — связка с игрой (`life.js`): состояние питомца → анимация, касания головы/ушей/хвоста.

Собранный файл `app/src/main/assets/fox3d.bundle.js` уже лежит в проекте. Пересборка после правок:

```bash
cd tools/web
npm install
npm run build
```

Проверить в браузере без телефона: `cd app/src/main/assets && python3 -m http.server`, затем открыть
`http://localhost:8000/index.html` (игра) или `overlay.html?stage=3` (плавающая лиса).
